# Data Visualization Techniques

## Repository Purpose

This repository serves as a record of laboratory work completed for the Data Visualization Techniques course.

It has been created to:

- Maintain a structured collection of laboratory experiments.
- Store source code, datasets, outputs, and supporting files.
- Track the completion of practical exercises.
- Provide evidence of coursework completion and hands-on implementation.

---

## Dataset

**File:** `pbp2026.csv`
NBA 2025-26 season play-by-play data, containing game id, period, clock, scores, team, player, event type, shot coordinates, shot distance and event description for every logged play.

---

## Repository Contents

| Folder | Description |
|---|---|
| `EXPERIMENT-I` | Basic data visualization techniques: line chart, bar chart, pie chart, histogram, box plot, scatter plot |
| `EXPERIMENT-II` | Advanced data visualization techniques: correlation heatmap, density heatmap, pair plot, violin plot, multi-panel dashboard |
